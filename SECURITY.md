# Security policy

If you find a security problem in StratLab (stratlab.studio), please tell us privately rather than in a public issue.

- Email **support@stratlab.studio** with "Security" in the subject.
- Say what you found, how to reproduce it, and what it could affect.
- Please don't access other people's data, run load or denial-of-service tests, or use automated scanners against the live site.

We aim to reply within 3 working days and will tell you when it's fixed.
